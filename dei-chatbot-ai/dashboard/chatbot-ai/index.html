Knowledge Base

Sumber jawaban AI. Semakin lengkap, semakin akurat.

Format CSV: category, question, answer — pemisah koma atau titik-koma, baris header opsional. Entri hasil impor masih bisa diperiksa/diedit sebelum Anda klik Simpan Perubahan. Unduh template CSV

Kategori Topik

Dipakai untuk tag Topik di entri KB dan kategori notif agent. Kategori bawaan tidak dapat dihapus. Kategori yang masih dipakai KB/pengguna juga tidak dapat dihapus.

Daftar ini jadi satu-satunya sumber harga bagi bot: menang atas Knowledge Base, dan bot dilarang menghitung total — ia hanya menyebut harga satuan lalu mengarahkan ke tim Anda.

Penting: hapus entri harga lama di tab Entri KB. Kalau dua tempat memuat angka berbeda, bot bisa memakai yang salah tanpa ketahuan.

Pemasangan via Google Tag Manager

Pasang widget di website mana pun tanpa mengubah kode HTML.

Langkah Pemasangan

  1. Buka Google Tag Manager → pilih container website Anda.
  2. Klik Tags → New → Tag Configuration → Custom HTML.
  3. Tempel kode di bawah ini ke kotak HTML.
  4. Triggering → pilih All Pages.
  5. Beri nama (mis. "DEI Chatbot") → Save → Submit / Publish.
